## Порядок

```
W2 -> W3 -> W4 -> W5
              X_оживить_конфиг — независим, можно параллельно
```

## Правила запуска

- Один пакет за раз. Кодеру не давать два пакета сразу: приёмка размывается.
- Гейт после каждого прогонять самому, не по отчёту кодера (`OWNERSHIP.md` §9: решение о мерже принимает Вова, не
  автор).
- Числа приёмки в промптах замерены при планировании. Если прогон кодера даёт другое — это находка, а не повод править
  спек.
- Коммит кодер не делает.
