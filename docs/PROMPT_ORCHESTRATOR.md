# Промпт запуска фазы

Роли агентов заданы в `.claude/agents/`, инварианты — в `AGENTS.md`. Здесь только
задание. От фазы к фазе меняется одна строка — её номер.

---

```
Спланируй фазу Ф0 и проведи её до зелёного гейта.

ЧИТАТЬ ПЕРЕД ПЛАНИРОВАНИЕМ:
  AGENTS.md                            инварианты и определение готовности
  docs/TASKS.md                        главный вход, раздел Ф0
  docs/ARCHITECTURE.md                 пайплайн, форматы данных
  docs/SCOPE.md                        границы работ
  reference/scripts/validate_10.rb     контракт жёстче, чем ТЗ
  reference/data/reference_decisions.json

ПЛАН
Разрежь фазу на пакеты. Пакет = один заход кодера, проверяемый одной командой.
Не проверяется одной командой — режь дальше.

На каждый пакет:
  ID из TASKS.md
  файлы, которые создаются или меняются
  сигнатуры публичных методов
  зависимости от других пакетов
  бриф кодеру — самодостаточный, он плана не видел
  команда проверки и признак успеха в её выводе

Затем: граф зависимостей и что идёт параллельно, гейт фазы с точной командой,
и что в этой фазе может сломаться молча.

ИСПОЛНЕНИЕ
Кодеру — по одному пакету за раз. Готовность объявляешь ты, после PASS.
FAIL — новый бриф с логом дословно, не пересказом.
Три FAIL подряд по пакету — стоп и вопрос человеку: скорее всего противоречие
в документах, а не баг в коде.

ОГРАНИЧЕНИЯ
Rails, БД, очереди и веб пока не нужны. Появится причина завести — спроси,
молча не заводи. Библиотеки не ограничены, бери что удобно.
Нейросети и ML внутри кода запрещены правилами хакатона.
Остальные инварианты — в AGENTS.md, они обязательны.

НЕ ДЕЛАТЬ
Не пересматривать архитектуру: противоречия выпиши списком в конец и работай
по приоритету документов. Не тащить задачи из других фаз. Не писать код самому.

ФОРМАТ
Таблица пакетов → граф → гейт → риски. Брифы отдельными блоками. Без вступления.
```

---

## Как пользоваться

Фазы запускать по одной: план Ф1 зависит от того, какие сигнатуры реально
получились на Ф0. После закрытия фазы отметить сделанное в `docs/TASKS.md`.

На Ф0 `make gate` упадёт, пока нет `Gemfile` — это `BLOCKED`, а не провал.
Создание `Gemfile` и есть часть Ф0.
